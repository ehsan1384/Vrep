# بهینه‌ساز استراتژی معامله طلا (XAUUSD)

سیستم بک‌تست و بهینه‌سازی برای طلای فارکس با شرایط زیر:

- سرمایه اولیه: **۵۰۰ دلار**
- اهرم: **۱:۲۰۰**
- تایم‌فریم: **M1** (یک دقیقه)
- سشن معاملاتی: **آمریکا (نیویورک)** — تقریباً ۱۳:۰۰ تا ۲۱:۰۰ UTC
- در پایان سشن آمریکا **همه معاملات بسته** می‌شوند
- سود/ضرر روزانه محاسبه و ثبت می‌شود
- لوپ با **ترکیب اندیکاتورها** و **پارامترهای مختلف** تکرار می‌شود
- در پایان، **بالاترین سود** و **استراتژی برنده‌** گزارش می‌شود
- بازه پیش‌فرض بک‌تست: **۳۰ روز** (یک ماه گذشته)

## نتیجه آخرین اجرا (۳۰ روز)

- بازه: ۲۰۲۶-۰۷-۰۸ تا ۲۰۲۶-۰۸-۰۶
- بهترین استراتژی: `ema_rsi`
- سود کل: **+۶۲.۴۶ USD** (۵۰۰ → ۵۶۲.۴۶)
- نرخ برد: ۵۵.۴۱٪ | افت حداکثر: ۵.۷۴٪ | ۱۴۶۹ معامله

## استراتژی‌های تست‌شده

| نام | توضیح |
|-----|--------|
| `ema_rsi` | کراس EMA + فیلتر RSI |
| `macd_stoch` | کراس MACD + Stochastic |
| `bb_rsi` | برگشت بولینگر + RSI |
| `trend_adx` | روند EMA با فیلتر ADX |
| `combo_triple` | رأی‌گیری سه‌گانه |
| `momentum_burst` | مومنتوم ترکیبی |

## اجرا

```bash
cd gold_optimizer
pip install -r requirements.txt
python3 main.py
```

پارامترهای اختیاری:

```bash
python3 main.py --max-combos 80 --top 10
```

## خروجی‌ها

- `results/best_summary.json` — بهترین استراتژی + پارامترها + PnL روزانه
- `results/all_results.csv` — همه ترکیب‌های تست‌شده
- `data/xauusd_m1.csv` — داده M1 (مصنوعی واقعی‌نما؛ قابل جایگزینی با داده واقعی)
