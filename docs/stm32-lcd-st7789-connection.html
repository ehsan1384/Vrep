اتصال LCD 3.2 اینچ ST7789 (37 پین) به STM32F103RCT6

نکته مهم: ماژول‌های 3.2 اینچ با کانکتور 37 پین معمولاً رابط Parallel 16-bit MCU (8080) دارند، نه SPI. میکروکنترلر STM32F103RCT6 (پکیج 64 پین) فاقد FSMC است؛ بنابراین باید با GPIO بیت‌بنگ کار کنید.

۱. مقایسه رابط Parallel و SPI

ویژگی ماژول 37 پین ماژول SPI (7–8 پین)
رابط 16bit Parallel SPI
سیگنال‌های داده DB0 تا DB15 + کنترل SCK, MOSI, DC, RST
پیچیدگی بالا (حدود 21 پین GPIO) پایین (حدود 5–6 پین)

۳. نحوه اتصال به STM32F103RCT6

۳.۱ تغذیه و بک‌لایت

LCD Pin 5, 34 (GND)   ──► GND برد STM32
LCD Pin 6, 32, 33     ──► 3.3V برد STM32
LCD Pin 15 (LEDA)     ──► 3.3V (ترجیحاً از طریق مقاومت 100Ω یا ترانزیستور)
LCD Pin 16-20 (LEDK)  ──► GND
بک‌لایت این ماژول از 5 عدد LED تشکیل شده و جریان کشی بالایی دارد. بهتر است از پین GPIO با ترانزیستور NPN یا MOSFET برای کنترل روشن/خاموش استفاده کنید.

۴.۳ نوشتن داده روی باس Parallel

void LCD_WriteData16(uint16_t data) {
    // DB0-DB7 روی Port A
    GPIOA->ODR = (GPIOA->ODR & 0xFF00) | (data & 0x00FF);
    // DB8-DB15 روی Port B (با در نظر گرفتن پین‌های استفاده‌شده)
    // ... تنظیم بیت‌های مربوطه

    LCD_CS_LOW();
    LCD_RS_DATA();
    LCD_WR_LOW();
    LCD_WR_HIGH();  // لبه بالارونده = نوشتن
    LCD_CS_HIGH();
}

void LCD_WriteCmd(uint8_t cmd) {
    LCD_CS_LOW();
    LCD_RS_CMD();
    // ... ارسال cmd
    LCD_CS_HIGH();
}

۴.۴ توالی راه‌اندازی ST7789

void ST7789_Init(void) {
    // Reset
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_1, GPIO_PIN_RESET);
    HAL_Delay(10);
    HAL_GPIO_WritePin(GPIOB, GPIO_PIN_1, GPIO_PIN_SET);
    HAL_Delay(120);

    LCD_WriteCmd(0x11);   // Sleep Out
    HAL_Delay(120);
    LCD_WriteCmd(0x36);   // Memory Access Control
    LCD_WriteData16(0x00);
    LCD_WriteCmd(0x3A);   // Pixel Format
    LCD_WriteData16(0x05); // 16-bit RGB565
    LCD_WriteCmd(0x21);   // Inversion ON (بسته به پنل)
    LCD_WriteCmd(0x29);   // Display ON
}

۵. نکات مهم

  • ولتاژ 3.3V: هر دو برد باید 3.3V باشند؛ 5V به LCD نزنید.
  • /RD ثابت: برای فقط نوشتن، /RD را به 3.3V وصل کنید.
  • کندی بیت‌بنگ: بدون FSMC، رفرش کامل صفحه کند است.
  • تاچ: اگر تاچ رزیتسیو (RTP) دارید، معمولاً کانکتور جداگانه دارد.
  • جایگزین بهتر: ماژول SPI (7–8 پین) برای F103 راحت‌تر است.

۶. عیب‌یابی (صفحه سیاه)

  • سیگنال‌های RESET، CS، RS و WR را با مولتی‌متر بررسی کنید.
  • ترتیب پین‌های DB0 تا DB15 را با دیتاشیت ماژول تطبیق دهید.
  • در رجیستر 0x36 (MADCTL) جهت را امتحان کنید: 0x00, 0x60, 0xC0, 0xA0.
  • دستورات 0x21 / 0x20 (Display Inversion) را تست کنید.
