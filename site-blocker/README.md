# Site Blocker

افزونه Chrome برای مسدود کردن سایت‌های دلخواه.

## نصب

1. Chrome را باز کنید و به `chrome://extensions` بروید
2. **Developer mode** را در گوشه بالا فعال کنید
3. روی **Load unpacked** کلیک کنید
4. پوشه `site-blocker` را انتخاب کنید

## استفاده

1. روی آیکون افزونه کلیک کنید و **مدیریت سایت‌ها** را بزنید
2. دامنه‌هایی مثل `twitter.com` یا `youtube.com` را اضافه کنید
3. با سوییچ بالا می‌توانید مسدودسازی را موقتاً خاموش/روشن کنید

وقتی سایتی مسدود باشد، به جای آن صفحه «این سایت مسدود است» نمایش داده می‌شود.

## نکات

- فقط دامنه را وارد کنید (بدون `https://`)
- زیردامنه‌ها هم مسدود می‌شوند (مثلاً `www.twitter.com`)
- تنظیمات با `chrome.storage.sync` ذخیره می‌شود
