# طلای بازار اصلی — نمودار ۱ دقیقه + عمق خرید/فروش

این ابزار قیمت و حجم قرارداد آتی طلای **COMEX** (`GC=F`) را نشان می‌دهد؛ نه دفتر سفارش بروکر فارکس.

## چرا COMEX؟

بازار نقدی فارکس طلا (`XAUUSD`) دفتر سفارش متمرکز عمومی ندارد.
نزدیک‌ترین بازار شفاف و اصلی طلا، قرارداد آتی `COMEX Gold` است.

## چه چیزی نمایش داده می‌شود؟

1. **نمودار شمعی ۱ دقیقه‌ای** طلای COMEX
2. **عمق بازار (Volume-at-Price)**  
   - حجم خریداران در هر سطح قیمت (از کندل‌های صعودی)  
   - حجم فروشندگان در هر سطح قیمت (از کندل‌های نزولی)
3. **جدول قیمت / حجم خرید / حجم فروش**

> عمق کامل زنده `Level 2` بورس CME نیاز به دیتافید پولی دارد (مثل Databento یا Bloomberg).  
> این نسخه رایگان، پروفایل حجم واقعی معاملات ۱ دقیقه‌ای همان بازار اصلی را می‌سازد.

## نصب و اجرا

```bash
cd gold_market
python3 -m pip install -r requirements.txt
python3 -m streamlit run app.py
```

اگر `streamlit: command not found` دیدید، حتماً با `python3 -m streamlit` اجرا کنید (نه خود دستور `streamlit`).

نسخه خط فرمان (خروجی HTML/CSV):

```bash
python3 chart_cli.py
```

فایل‌ها در پوشه `output/` ذخیره می‌شوند.

## فایل‌ها

| فایل | توضیح |
|------|--------|
| `app.py` | داشبورد Streamlit |
| `chart_cli.py` | خروجی HTML بدون UI |
