# سنسور ۴ سوراخ پود با پیزوالکتریک

طراحی سخت‌افزاری سنسور تشخیص حرکت/پارگی پود بافندگی با **۴ سوراخ سرامیکی** و **۴ المان پیزوالکتریک** مستقل.

## اصل کار

پود هنگام عبور از سوراخ سرامیکی باعث ارتعاش مکانیکی می‌شود. این ارتعاش به دیسک `piezo` منتقل شده و بار الکتریکی تولید می‌کند:

- **پود در حال حرکت** → سیگنال `AC` با دامنه مشخص
- **پارگی پود / توقف حرکت** → افت دامنه → خروجی توقف ماشین
- **تنش کم** → کاهش دامنه (قابل تنظیم با حساسیت)

این اصل در سنسورهای صنعتی مانند `ROJ TFE-6`، `Eltex EVG` و سنسورهای `JWJW` استفاده می‌شود.

## مشخصات هدف

| پارامتر | مقدار |
|---------|--------|
| تعداد کانال | ۴ |
| قطر سوراخ (قابل تعویض) | `0.8 / 1.0 / 1.2 / 1.5 mm` |
| تغذیه | `24 V DC` صنعتی (`17–30 V`) |
| جریان مصرفی | `< 80 mA` (۴ کانال) |
| خروجی | `4×` اپتوکوپلر `open collector` |
| زمان واکنش | `< 150 ms` |
| حساسیت | تنظیم آنالوگ مستقل هر کانال |
| دمای کار | `0 … +60 °C` |
| جنس سوراخ | سرامیک `Al₂O₃` (آلومینا) |

## نکته مهم نصب

- بدنه فلزی سنسور و **شیلد** باید به `PE` (ارت زمین محافظ) وصل شوند.
- منفی تغذیه `24V` باید به زمین ماشین متصل باشد (مطابق استاندارد سنسورهای صنعتی).
- سوراخ‌ها باید در یک خط با مسیر پود هم‌محور باشند تا کشش اضافه ایجاد نشود.
