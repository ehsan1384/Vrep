## سوراخ سرامیکی (Eyelet)

### مشخصات

| پارامتر | مقدار پیشنهادی |
|---------|----------------|
| جنس | آلومینا `Al₂O₃` ۹۹٪ |
| قطر داخلی استاندارد | `1.0 mm` (نسخه‌های `0.8 / 1.2 / 1.5` قابل سفارش) |
| زاویه ورودی | `chamfer 60°` هر دو طرف |
| صیقل داخلی | `Ra ≤ 0.4 µm` |
| سختی | `HV 1500+` |

### چرا سرامیک؟

- اصطکاک پایین با الیاف
- مقاوم در برابر سایش
- انتقال ارتعاش یکنواخت به پین انتقال
- استاندارد صنعتی (`Eltex`، `ROJ`، `JWJW`)

### نصب سوراخ

```
سوراخ سرامیک → فشرده در حلقه برنجی (brass bushing)
حلقه برنجی → پیچ‌خور در بدنه آلومینیوم
```

گشتاور پیچ: `0.3 N·m` (با واشر `PTFE` برای ضدچرخش)

## انتقال ارتعاش به Piezo

### پین انتقال (coupling pin)

| پارامتر | مقدار |
|---------|--------|
| جنس | فولاد ضدزنگ `AISI 303` |
| قطر | `1.5 mm` |
| طول | `6 mm` |
| سر تماس با پود | نیم‌کره `R0.3` صیقلی |

### فنر پیش‌بار (preload spring)

| پارامتر | مقدار |
|---------|--------|
| نوع | فنر فشاری استوانه‌ای |
| جنس | فولاد فنری `SWP-B` |
| قطر سیم | `0.3 mm` |
| قطر خارجی | `3 mm` |
| طول آزاد | `8 mm` |
| پیش‌بار | `0.15 – 0.25 N` |
| هدف | تماس مکانیکی پایدار بدون گیر کردن پود |

> پیش‌بار زیاد → کشش اضافه روی پود → پارگی کاذب  
> پیش‌بار کم → سیگنال ضعیف

## دیسک پیزوالکتریک

| پارامتر | مقدار |
|---------|--------|
| نوع | دیسک برقی `piezo ceramic disc` |
| قطر | `20 mm` |
| ضخامت | `0.35 mm` |
| ظرفیت | `15 – 25 nF` (بی‌بار) |
| مثال مرجع | `Murata 7BB-20-6L0` یا معادل چینی `FT-20` |

### جهت نصب

- الکترود مثبت (رویی) → تماس با پین انتقال
- الکترود منفی (پشتی) → لحیم به پد `PCB` با چسب رسانای نقره‌ای (`CW2400`)

## بدنه و متریال

| قطعه | متریال | توضیح |
|------|--------|--------|
| بدنه اصلی | آلومینیوم `6061-T6` آنادایز مشکی | ماشین‌کاری `CNC` |
| پوشش بالا | روی `Zamak` یا `PA66-GF30` | محافظ در برابر پرتاب |
| صفحه `PCB` | نگهدارنده پایه `piezo` | ۴ پد لحیم در یک صفحه |
| شیلد | ورق برنج `0.3 mm` | اتصال به `PE` |

## نکات مونتاژ مکانیکی

1. **ترتیب مونتاژ:** `PCB` → لحیم `piezo` → نصب فنر و پین → نصب سوراخ سرامیک → بستن پوشش
2. **عایق‌بندی:** لاک عایق (`MG Chemicals 422B`) روی لحیم `piezo`
3. **تست مکانیکی:** عبور نخ تست `1200 denier` با سرعت دستی — نباید گیر کند
4. **گرد و غبار:** درز بدنه با اورینگ `NBR` سایز `1×2 mm`

## اتصال به قاب ماشین

- ۲ پیچ `M4×12` با فاصله `58 mm`
- واشر لرزه‌گیر `M4` سیلیکونی بین بدنه و براکت
- امکان چرخش `±15°` برای تنظیم زاویه ورود پود (براکت لولایی اختیاری)
