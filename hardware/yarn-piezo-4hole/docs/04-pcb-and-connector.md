# PCB، کانکتور و EMC

## مشخصات PCB

| پارامتر | مقدار |
|---------|--------|
| نام برد | `YP4H-MAIN Rev A` |
| ابعاد | `70 × 25 mm` |
| لایه | `2L` (`Top` + `Bottom`) |
| ضخامت | `1.6 mm` |
| روکش | `HASL` یا `ENIG` (پیشنهاد `ENIG` برای پد `piezo`) |
| مسیر آنالوگ | `0.25 mm` حداقل |
| مسیر تغذیه `24V` | `0.8 mm` |

## چیدمان (Placement)

```text
  [J2 DB15]                                    [J1 Power 2-pin]
      |                                              |
  ┌───┴──────────────────────────────────────────────┴───┐
  │  CH1    CH2    CH3    CH4     (analog strip)         │
  │ [VR1]  [VR2]  [VR3]  [VR4]   sensitivity pots      │
  │  LED1   LED2   LED3   LED4                          │
  │                                                       │
  │  U4-U7 (opamps)          U1 Buck         U8 LM393    │
  │                                                       │
  │  [Piezo pad 1] [Piezo pad 2] [Piezo pad 3] [Piezo pad 4]  │
  └───────────────────────────────────────────────────────┘
         ↑ لبه نصب به بدنه آلومینیوم با ۲ پیچ M3
```

### قوانین چیدمان

1. هر کانال آنالوگ در یک «جزیره» با `guard ring` دور پد `piezo`
2. اپ‌امپ‌ها حداکثر `8 mm` از پد `piezo` همان کانال
3. باک و مقایسه‌گرها در نیمه دور از پد‌های حساس
4. پتانسیومترها در لبه برد برای دسترسی از سوراخ بدنه (`Ø3 mm`)

## پد Piezo

| پارامتر | مقدار |
|---------|--------|
| شکل | دایره `Ø20 mm` |
| الکترود مرکزی | پد `Ø8 mm` (لحیم سیم پین) |
| حلقه زمین | `guard ring` با فاصله `0.5 mm` |
| سوراخ مرکزی | `Ø1.5 mm` برای پین انتقال (بدون لحیم) |

## کانکتور `J2` — `DB15` ماده (پین نر)

| Pin | سیگنال | نوع | توضیح |
|-----|--------|-----|--------|
| 1 | `+24V` | Power in | |
| 2 | `GND` | Power | منفی تغذیه — به `PE` ماشین |
| 3 | `CH1_OUT` | Open collector | اپتو کانال ۱ |
| 4 | `CH2_OUT` | Open collector | |
| 5 | `CH3_OUT` | Open collector | |
| 6 | `CH4_OUT` | Open collector | |
| 7 | `OUT_COM` | Common | مشترک اپتوها (emitter) |
| 8 | `SHIELD` | Shield | پوسته کابل و بدنه |
| 9 | `ENABLE` | Input | `LOW` = غیرفعال سنسور (اختیاری `Rev B`) |
| 10 | `STATUS` | Open collector | خطای کلی (هر ۴ کانال `OR`) |
| 11–15 | `NC` | — | رزرو `UART`/`CAN` |

### نماد سیم‌کشی کابل ماشین

```text
DB15 socket (روی سنسور) ←→ کابل شیلد‌دار 6×0.25mm² + drain wire
  +24V  → قرمز
  GND   → سیاه
  CHx   → سفید/زرد/سبز/آبی
  SHIELD → به پوسته فلزی بدنه سنسور
```

## کانکتور تغذیه `J1` (اختیاری موازی)

`Phoenix Contact 1757018` ۲ پین `5.08 mm` برای تغذیه مستقیم در کنار `DB15`.

## لایه شیلد

- نواحی خالی `Bottom` با `copper pour` متصل به `SHIELD`
- اتصال شیلد به بدنه از **یک** پیچ `M3` نزدیک `J2`
- **هرگز** شیلد را مستقیم به `AGND` و `DGND` همزمان وصل نکنید

## جدول ولتاژ تست

| نقطه | ولتاژ نرمال |
|------|-------------|
| `+24V` | `24 ± 2 V` |
| `+5V` | `5.0 ± 0.1 V` |
| `+3V3` | `3.3 V` |
| خروجی envelope (پود فعال) | `0.5 – 2.5 V DC` |
| آستانه مقایسه‌گر | `0.2 – 1.5 V` (با `VR1`) |
