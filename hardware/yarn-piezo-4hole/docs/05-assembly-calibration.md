# مونتاژ و کالیبراسیون

## مراحل مونتاژ

### مرحله ۱ — برد الکترونیک

1. لحیم `SMD` باک و اپ‌امپ‌ها (ریفلو `250°C`)
2. لحیم `through-hole`: پتانسیومتر، `DB15`، اپتو، `LED`
3. شستشوی برد (در صورت استفاده از فلاکس آبی)
4. تست تغذیه: `24V` → بررسی `+5V` و `+3V3`

### مرحله ۲ — Piezo

1. چسب رسانای نقره (`CW2400`) روی پد منفی `piezo`
2. فشار `5N` به مدت `10 s` — خشک شدن `2 h`
3. لحیم سیم `30 AWG` از الکترود مثبت به پین انتقال (نه مستقیم به `PCB`)

### مرحله ۳ — مکانیک

1. نصب `PCB` در بدنه با `2× M3`
2. قرار دادن فنر + پین روی هر `piezo`
3. فشردن سوراخ سرامیک — تنظیم پیش‌بار
4. بستن درب — تست عبور نخ دستی

### مرحله ۴ — کابل

1. `DB15` با گیره کشش
2. `ferrite bead` `10 cm` بعد از کانکتور
3. تست پین‌به‌پین با مولتی‌متر

## تجهیزات تست

| تجهیز | کاربرد |
|-------|--------|
| منبع تغذیه `24V/1A` | تغذیه سنسور |
| اسیلوسکوپ | مشاهده سیگنال `AC` از `piezo` |
| مولتی‌متر | ولتاژ envelope و آستانه |
| نخ تست `150 denier` | شبیه‌سازی پود |
| موتور کوچک + غلطک | کشیدن نخ با سرعت ثابت |

## روش کالیبراسیون

### گام ۱ — سیگنال پایه (بدون پود)

1. تغذیه روشن، ۴ سوراخ خالی
2. `VR1…VR4` را کامل **ساعتگرد** بچرخانید (حساسیت max)
3. `LED` باید قرمز (پارگی) باشد

### گام ۲ — با پود در حرکت

1. نخ را از هر ۴ سوراخ رد کنید با سرعت `~5 m/min`
2. `VRx` را **پادساعتگرد** بچرخانید تا `LED` سبز شود
3. نخ را بگیرید → `LED` باید در `< 150 ms` قرمز شود
4. تکرار برای هر ۴ کانال **مستقل**

### گام ۳ — حاشیه امنیت

- آستانه را `10–15%` پایین‌تر از نقطه تریگر تنظیم کنید
- تست با پود نازک‌تر و ضخیم‌تر مجاز
- تست با رطوبیت `60%` (محیط واقعی کارگاه)

## جدول عیب‌یابی

| علامت | علت محتمل | راه‌حل |
|-------|-----------|--------|
| همیشه پارگی | حساسیت خیلی بالا / `piezo` شکسته | کاهش `VR`، تعویض `piezo` |
| هیچ‌وقت پارگی تشخیص نمی‌دهد | حساسیت خیلی پایین | افزایش `VR`، بررسی پین انتقال |
| سیگنال نویزی | زمین ضعیف / `EMI` | تقویت شیلد، `ferrite` |
| یک کانال ضعیف | لحیم `piezo` | بازلحیم با چسب رسانا |
| پود می‌گیرد در سوراخ | سوراخ کوچک / خراش | تعویض سوراخ، صیقل |
| تریگر کاذب با لرزش ماشین | `BPF` نادرست | افزایش فرکانس قطع پایین |

## پارامترهای ثبت کالیبراسیون

برای هر دستگاه سریال `YP4H-XXXX` ثبت کنید:

| فیلد | مثال |
|------|------|
| قطر سوراخ | `1.0 mm` |
| نوع پود تست | `150 denier polyester` |
| سرعت تست | `5 m/min` |
| موقعیت `VR1` | `3.2 turns` |
| زمان واکنش اندازه‌گیری | `95 ms` |
| تاریخ | `2026-06-28` |

## نگهداری دوره‌ای

| بازه | کار |
|------|-----|
| هر هفته | بازرسی گیر نکردن پود |
| هر ماه | تست پارگی مصنوعی |
| هر ۶ ماه | بازرسی سایش سوراخ سرامیک |
| سالانه | تعویض سوراخ در صورت خط و خش عمقی |

## ایمنی

- کار روی ماشین در حال حرکت فقط با قفل `LOTO`
- ولتاژ `24V` صنعتی — اتصال قطبی صحیح
- لحیم `piezo` — حرارت `< 3 s @ 300°C` (خطر ترک سرامیک)
