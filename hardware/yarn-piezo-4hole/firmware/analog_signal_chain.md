# زنجیره پردازش سیگنال (آنالوگ)

## مدل سیگنال Piezo

دیسک `piezo` در تماس با پین انتقال، ولتاژ `AC` تولید می‌کند:

```
V_piezo(t) = A · sin(2πft) + noise
```

| پارامتر | محدوده معمول |
|---------|--------------|
| فرکانس `f` | `200 Hz – 5 kHz` (وابسته به سرعت پود و تنش) |
| دامنه `A` | `5 – 200 mVpp` |
| امپدانس | ظرفیت `~20 nF` (بسیار بالا در `DC`) |

## مراحل پردازش

### ۱. جداسازی و بایاس (`C_series` + `R1`)

- حذف افست `DC`
- `R1 = 10M` مسیر تخلیه بار

### ۲. تقویت بافر (`TL072`)

- بهره `×1` — هدف: امپدانس پایین برای فیلتر بعدی
- حفظ دامنه اصلی

### ۳. فیلتر `Band-pass`

حذف:
- نویز برق `50/60 Hz`
- ارتعاش ساختاری ماشین `< 80 Hz`
- نویز فرکانس بالا `> 8 kHz`

### ۴. Envelope

تبدیل `AC` به `DC` متناسب با دامنه:

```
V_env = peak_detect(V_bp) → low-pass τ ≈ 100–200 ms
```

### ۵. مقایسه با آستانه

```
if V_env < V_th for t > 120 ms → FAULT (yarn break)
```

تأخیر `120 ms` از `C5` و `R5` — جلوگیری از تریگر کاذب لحظه‌ای

## تنظیم حساسیت (`VR1`)

```
V_th = V_ref × (VR_position / 10k)
```

| موقعیت `VR` | رفتار |
|-------------|--------|
| ساعتگرد (max) | حساسیت بالا — پود آرام هم تشخیص داده می‌شود |
| پادساعتگرد (min) | حساسیت پایین — فقط ارتعاش قوی |

## تبدیل به نسخه دیجیتال (`Rev B`)

```c
// Pseudocode — STM32F030
#define SAMPLE_RATE_HZ  8000
#define BPF_TAPS        64
#define THRESHOLD_MV    400
#define FAULT_DELAY_MS  120

float bpf_process(int16_t raw_adc);
bool detect_break(float envelope);
```

| مرحله | الگوریتم |
|-------|----------|
| `ADC` | `DMA` circular، `12-bit` |
| `BPF` | `IIR biquad` @ `1 kHz` |
| Envelope | `abs()` + `EMA` `α=0.05` |
| تصمیم | `hysteresis` `±10%` |
