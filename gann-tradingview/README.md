## محدودیت‌های Pine Script (قبل از استفاده)

1. **حداکثر ~۵۰۰** `line`، `label` و `box` — آبجکت‌ها فقط روی **آخرین کندل** بازسازی می‌شوند.
2. **Anchor دستی** با «تعداد کندل قبل» (`Manual Anchor Bars Ago`) کار می‌کند؛ انتخاب دقیق با کلیک روی نمودار در Pine Script مستقیم ممکن نیست.
3. **زوایای گن** به‌صورت **شیب قیمت/زمان** (با `Scale Ratio`) تقریب زده می‌شوند — زاویه هندسی واقعی ۴۵° به مقیاس نمودار TradingView بستگی دارد.
4. **Square of 9** با فرمول آموزشی `(√P ± degree/180)²` پیاده شده؛ نسخه‌های مختلف گن (Wheel، Card) ممکن است اختلاف جزئی داشته باشند.
5. **Pivot** فقط پس از `rightBars` تأیید می‌شود — سیگنال‌ها **تأخیر** دارند و این **عمدی** است (جلوگیری از repaint).

---

## تئوری گن چیست؟

**W.D. Gann** معامله‌گر و تحلیل‌گر قرن بیستم بود که بر **تعادل قیمت و زمان** تأکید می‌کرد. برخلاف حمایت/مقاومت صرفاً قیمتی، گن می‌گفت:

- بازار در **زاویه ۱×۱** (تعادل) حرکت می‌کند.
- **زمان** می‌تواند مانند **قیمت** سطوح و نقاط برگشت ایجاد کند.
- ابزارهایی مثل **Fan**، **Box**، **Square of 9** و **Time Cycles** برای یافتن **نواحی احتمالی** هستند، نه پیش‌بینی قطعی.

---

## مفهوم تعادل قیمت و زمان

خط **۱×۱** یعنی به ازای هر واحد زمان (مثلاً ۱ کندل)، قیمت به‌طور متوسط ۱ واحد (با `Scale Ratio`) جابه‌جا شود.

- **بالای ۱×۱** → روند غالب صعودی (قدرت خریدار نسبت به زمان)
- **پایین ۱×۱** → روند غالب نزولی
- **شکست ۱×۱** → احتمال تغییر فاز (نیاز به تأیید چند کندلی)

---

## مفهوم زوایای ۱×۱، ۲×۱، ۳×۱ و سایر زوایا

| زاویه | معنی تقریبی |
|---|---|
| **۱×۱** | تعادل قیمت/زمان |
| **۲×۱** | صعود/نزول تند (۲ واحد قیمت در ۱ واحد زمان) |
| **۳×۱، ۴×۱، ۸×۱** | شیب‌های تهاجمی‌تر |
| **۱×۲** | حرکت کند (۱ واحد قیمت در ۲ واحد زمان) |
| **۱×۳، ۱×۴، ۱×۸** | حرکت بسیار کند — اغلب حمایت/مقاومت قوی‌تر |

در اندیکاتور: هر زاویه قابل خاموش/روشن است؛ رنگ **آبی/فیروزه‌ای** برای فن صعودی (از Pivot Low) و **نارنجی** برای فن نزولی (از Pivot High).

---

## روش انتخاب Anchor Point

**Anchor** نقطه مبدأ خطوط گن است.

| حالت | کاربرد |
|---|---|
| **Auto → Last Pivot Low** | فن صعودی از کف تأییدشده |
| **Auto → Last Pivot High** | فن نزولی از سقف تأییدشده |
| **Auto → Most Recent Pivot** | جدیدترین Pivot تأییدشده |
| **Manual** | قیمت و «کندل قبل» دلخواه |

**قانون طلایی:** Pivot تا `rightBars` کندل بعد تأیید نمی‌شود — Anchor از Pivot تأییدنشده ساخته **نمی‌شود**.

---

## نحوه تنظیم Scale Ratio

1. یک **Pivot Low** واضح انتخاب کنید (Auto).
2. `Scale Ratio` را طوری تنظیم کنید که خط **۱×۱** از Anchor، حرکت «متعادل» بازار را تقریب بزند.
3. در تایم‌فریم‌های مختلف Scale متفاوت است — برای هر TF جدا تنظیم کنید.
4. اگر ۱×۱ خیلی تند/کند است → `Scale Ratio` را کم/زیاد کنید.

---

## نحوه استفاده از Gann Fan در TradingView

1. اندیکاتور را اضافه کنید.
2. `Pivot Left/Right Bars` را تنظیم کنید (پیش‌فرض ۵).
3. `Anchor Mode` = Auto و منبع Pivot را انتخاب کنید.
4. `Show Gann Fan` = روشن.
5. برای شروع: فقط **۱×۱، ۲×۱، ۱×۲** (`Main Angles Only`).
6. **پنل** را ببینید: Active Angle، Support، Resistance.
7. **شکست ۱×۱** با `Break Confirmation Bars` (پیش‌فرض ۲) فیلتر می‌شود.

## نحوه استفاده از Gann Box

- بین **دو Pivot تأییدشده** (آخرین High و Low) رسم می‌شود.
- تقسیمات **۴، ۸ یا ۱۶** بخش — خطوط افقی/عمودی داخلی.
- **سبز/آبی** = ناحیه حمایتی پایین | **خاکستری** = خنثی | **نارنجی** = مقاومت بالا.
- تقاطع خطوط Box با Fan/So9 = **هم‌زمانی آموزشی** (امتیاز بیشتر در پنل).

---

## نحوه استفاده از Square of 9

**فرمول:**

```
سطح بالاتر = (√P + degree/180)²
سطح پایین‌تر = (√P - degree/180)²
```

- درجه‌ها: ۴۵°، ۹۰°، ۱۳۵°، … (گام ۴۵ یا ۹۰)
- `Reference Price` = ۰ → آخرین Pivot
- جدول در **پنل** + خطوط نزدیک‌ترین حمایت/مقاومت روی نمودار

**⚠ این سطوح نواحی احتمالی هستند — هرگز به‌تنهایی برای ورود استفاده نکنید.**

---

## نحوه استفاده از Time Cycles

چرخه‌های پشتیبانی‌شده (کندل): **۹، ۱۸، ۳۰، ۴۵، ۶۰، ۹۰، ۱۲۰، ۱۴۴، ۱۸۰، ۳۶۰**

- Anchor زمانی = Anchor فن یا آخرین Pivot Low
- خطوط عمودی = موعد چرخه‌های آینده
- **زرد** = نزدیک شدن به چرخه (`Cycle Proximity Warning`)

**⚠ چرخه فقط احتمال تغییر فاز را نشان می‌دهد — زمان دقیق برگشت تضمین نمی‌شود.**

---

## مثال بازار صعودی

1. Pivot Low تأیید در ۲۴۰۰
2. Anchor = Last Pivot Low → فن صعودی
3. قیمت بالای ۱×۱ → State: **Bullish**
4. پول‌بک به ۱×۲ → حمایت احتمالی؛ هم‌زمانی با So9
5. چرخه ۹۰ کندلی نزدیک → احتمال تغییر فاز؛ منتظر تأیید بمانید
6. شکست ۱×۱ با ۲ کندل بسته → هشدار؛ State ممکن است **Neutral/Bearish** شود

---

## مثال بازار نزولی

1. Pivot High تأیید در ۲۵۵۰
2. Anchor = Last Pivot High → فن نزولی
3. قیمت زیر ۱×۱ → **Bearish**
4. بازگشت به ۱×۲ از بالا → مقاومت احتمالی
5. Box: ناحیه بالایی (Bear Zone) + چرخه ۱۴۴
6. عبور و تثبیت بالای ۱×۱ → احتمال پایان فاز نزولی (آموزشی)

## تفاوت تحلیل گن با حمایت/مقاومت معمولی

| حمایت/مقاومت کلاسیک | گن |
|---|---|
| فقط **قیمت** | **قیمت + زمان** |
| خط افقی | خطوط مورب (Fan) + شبکه (Box) |
| سطوح گذشته | زوایا و چرخه‌های هندسی |
| تأیید با برخورد | تأیید با تعادل ۱×۱ + چرخه + هم‌زمانی |

## ترکیب گن با حجم، ساختار بازار و MA

1. **ساختار بازار:** Higher High/Low قبل از Fan صعودی
2. **MA (۵۰):** هم‌جهت با State → امتیاز بیشتر در پنل
3. **حجم:** (خارج از این اسکریپت) — در Pivot و شکست ۱×۱ حجم بالاتر = تأیید قوی‌تر
4. **قانون:** حداقل **۲ منبع مستقل** (مثلاً Fan + Pivot + MA) قبل از هر تصمیم

## محدودیت‌های آماری و عدم قطعیت

- تئوری گن **علمی اثبات‌شده** نیست؛ backtest گذشته‌نگر است.
- پارامترها (`Scale`، `Pivot bars`) overfit می‌شوند.
- بازارهای مختلف (طلا، سهام، کریپتو) رفتار متفاوت دارند.
- **امتیاز پنل آموزشی است** — آستانه‌ها قابل تغییر و ذهنی‌اند.

## نصب و استفاده در TradingView (گام‌به‌گام)

### ۱. باز کردن Pine Editor

1. وارد [TradingView.com](https://www.tradingview.com) شوید.
2. نمودار باز کنید (مثلاً `XAUUSD` یا `COMEX:GC1!`).
3. پایین صفحه **Pine Editor** را باز کنید.

### ۲. افزودن اندیکاتور

1. محتوای `gann_educational_toolkit.pine` را **کپی** کنید.
2. در Pine Editor **Paste** کنید.
3. **Save** → نامی مثل `Gann Educational Toolkit` بدهید.
4. **Add to chart**.

### ۳. تنظیمات اولیه

1. روی نام اندیکاتور کلیک → **Settings**.
2. **Pivot Left/Right** = ۵ (یا متناسب با TF).
3. **Anchor Mode** = Auto.
4. **Scale Ratio** را تا هم‌راستایی ۱×۱ تنظیم کنید.
5. **Show Main Angles Only** = روشن (شروع ساده).

### ۴. افزودن استراتژی (اختیاری)

1. فایل `gann_strategy_example.pine` را در Pine Editor جدید Paste کنید.
2. **Add to chart** — در تب **Strategy Tester** نتایج را ببینید.
3. **Commission** و **Slippage** را در Settings استراتژی تنظیم کنید.

### ۵. هشدار (Alert)

1. روی نمودار → آیکن **Alert** (زنگوله).
2. Condition = `Gann Educational Toolkit`.
3. یکی از: `1x1 Break`، `Near Square of 9`، `Near Time Cycle`، `State Change`.
4. **Once per bar close** را انتخاب کنید.

## سیستم امتیازدهی (Indicator)

| عامل | امتیاز تقریبی |
|---|---|
| بالای/زیر ۱×۱ | ±۲۰ |
| شکست ۱×۱ تأییدشده | ±۱۵ |
| نزدیک Pivot Low/High | ±۱۰ |
| بالای/زیر MA | ±۱۰ |
| نزدیک So9 | ±۵ (هشدار) |
| Time Cycle نزدیک | ۰ (فقط هشدار بصری) |

- **≥ ۳۵** → Bullish  
- **≤ -۳۵** → Bearish  
- بین آن‌ها → Neutral

## هشدارها (Alerts)

| Alert | شرط |
|---|---|
| 1x1 Break | شکست ۱×۱ + تأیید `confirmBars` |
| Near Square of 9 | فاصله ≤ `Level Proximity Threshold` |
| Near Time Cycle | ≤ `Cycle Proximity Warning` کندل |
| State Change | Bullish ↔ Bearish |

همه هشدارها **فقط پس از بسته شدن کندل** (`barstate.isconfirmed`).
